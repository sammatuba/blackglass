# Generating the artifacts with ChatGPT (no API key)

The pipeline's contract is just: **PNGs with the manifest filenames land in `assets/`**. `gen-images.mjs` is only one way to put them there. This worksheet walks the same 7 artifacts through the ChatGPT UI (any paid plan) — normal product use, fully within terms, no OAuth bridges, no keys.

After the files exist, finish the pipeline (no key needed):

```bash
node gen-images.mjs --emit            # embed the PNGs into the browser mirror (artifacts.js)
node scripts/sync-artifacts.mjs       # copy them into the platform (src/games/blackglass/assets/artifacts)
```

**Ground rules while generating:**

- The manifest prompts below already encode the **planted tells**. After each generation, zoom in and check the tells listed under the prompt. If a tell didn't survive, regenerate — *the tell is the payload; a seamless image is a failed image.*
- Aspect matters more than exact pixels: `1200x900` = **landscape**, `900x1600` = **portrait/tall** (ask for it in the prompt). The runtime fits the image with CSS.
- Order is load-bearing: `kangkong` must exist before its two siblings, and `dr-anita-still` before `dr-anita-outro` — the followers are generated by **attaching the earlier image** and asking for the variant.
- Files go to `play/blackglass-phones/assets/<file>` exactly as named.

A photo of fresh kangkong (water spinach) on a dark teal-green background, with a thick hand-drawn RED CIRCLE around the bundle and a red diagonal slash, like it is being labelled dangerous. Top banner reads 'EXPOSED' in heavy yellow uppercase. Smaller faux-headline text below in white sans-serif. In a lower corner, a small inset stock-style headshot of a generic 'concerned doctor' in a white coat with a stethoscope. Garish, high-contrast, screenshot-of-a-forwarded-link aesthetic. Looks mass-produced for engagement.

Tells to verify: the red-circle urgency lever · a "doctor" who reads as stock-AI (too smooth, no name/institution) · small garbled text that doesn't survive a second look.
